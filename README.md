# Trabajo de fin de Master en Desarrollo de Interfaces de Usuario (Front-End).

![International University of la Rioja Logo](img/Logo_UNIR.svg)

## Objetivo del Proyecto

**Little Paws of Hope** es una aplicación móvil multiplataforma desarrollada como Trabajo de 
Fin de Máster del Máster Universitario en Diseño y Desarrollo de Interfaz de Usuario(Front-End).
El objetivo principal de la aplicación es facilitar el proceso de adopción de mascotas mediante
una plataforma intuitiva que permita a los usuarios explorar animales disponibles,
consultar información detallada y acceder a datos relevantes para su adopción.

El proyecto ha sido desarrollado utilizando React Native con Expo, TypeScript, NativeWind y
TanStack Query, aplicando buenas prácticas de desarrollo móvil moderno como la creación de componentes
reutilizables, arquitectura escalable, gestión eficiente de datos asíncronos y diseño de interfaces
adaptables centradas en la experiencia del usuario.
